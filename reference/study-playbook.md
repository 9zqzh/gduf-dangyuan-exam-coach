# 冲刺学习手册

## 核心原则

1. **高频优先**：先把反复考的主题吃透，再补冷门。
2. **以题带点**：每道错题都要回到知识点，而不是只记答案。
3. **主动回忆**：合上答案复述，比反复看讲义有效。
4. **间隔重复**：当天、第 2 天、第 4 天、第 7 天各回炉一次。
5. **输出倒逼输入**：简答先写骨架，再对照参考答案补漏。

## 先定计划

拿到考试日期后，按剩余天数选模板：

| 剩余时间 | 策略 | 目标 |
|---|---|---|
| 3 天以内 | 只保高频 + 错题 + 两套卷 | 客观题 70%+，简答有骨架 |
| 7 天 | 高频串讲 + 分题型突破 + 3 套模拟 | 稳定 75 分 |
| 14 天 | 高频 + 全主题覆盖 + 错题闭环 | 稳定 80 分 |
| 30 天 | 系统学习 + 每周模考 + 时政更新 | 85 分以上 |

默认每天可用时间：

- 60 分钟：40 分钟做题/回炉 + 20 分钟背诵。
- 90 分钟：50 分钟新内容 + 25 分钟错题 + 15 分钟简答默写。
- 120 分钟以上：增加一整节主题串讲和一套限时客观题。

## 7 天冲刺模板

| 天数 | 任务 | 产出 |
|---|---|---|
| D1 | 诊断 + 高频主题 1（二十大/中国式现代化） | 一张框架图，20 题 |
| D2 | 高频主题 2（党史）+ 单选专项 | 错题清单，30 题 |
| D3 | 高频主题 3（经济/高质量发展）+ 多选专项 | 易混对比表，30 题 |
| D4 | 党章党规 + 填空专项 | 固定表述清单，40 空 |
| D5 | 简答模板 + 4 道简答默写 | 4 篇骨架答案 |
| D6 | 整套模拟考 A + 逐题复盘 | 分数与失分原因表 |
| D7 | 错题回炉 + 高频速览 + 早睡 | 只看错题和框架 |

每天固定动作：

- 开始前 5 分钟：回顾昨天错题。
- 结束前 10 分钟：用 3 句话复述今天最重要的考点。
- 睡前：闭眼回忆 5 个关键词，想不起来第二天先补。

## 14 天模板

第一周：高频主题 + 分题型。

- D1—D2：二十大、中国式现代化、新思想。
- D3—D4：党史、党章、党的性质宗旨。
- D5—D6：经济、政治、文化、社会、生态。
- D7：第一次模拟考 + 复盘。

第二周：补漏 + 输出。

- D8—D9：纪律处分条例、组织制度、党员发展。
- D10—D11：政协统战、国防军队、外交、时政。
- D12：简答专题，整理 10 个万能骨架。
- D13：第二次模拟考 + 错题回炉。
- D14：只看错题、易混表、简答骨架。

## 每日 90 分钟样板

```text
00—05  回顾昨日错题（3—5 题）
05—35  新主题串讲：框架 → 3 个考点 → 1 个易混点
35—60  对应练习 20—25 题，即时看解析
60—75  错题回炉：写错误原因 + 正确表述
75—85  简答默写 1 题（只写骨架）
85—90  今日 3 句话总结
```

## 错题闭环

每道错题只做三件事：

1. **标原因**：知识盲区 / 概念混淆 / 审题失误 / 表述不熟 / 时政过时。
2. **写正确表述**：用一句话写下正确版本，不要抄整段。
3. **安排回炉**：第 2 天、第 4 天、第 7 天各做一次；连续 3 次答对才移出错题本。

常见错误原因与对策：

| 原因 | 表现 | 对策 |
|---|---|---|
| 知识盲区 | 完全没见过 | 回到主题框架，补 1 个知识块 |
| 概念混淆 | 两个相似表述选错 | 做 2 列对比表，只记差异 |
| 审题失误 | 问“错误”却选“正确” | 圈出题干限定词再选 |
| 表述不熟 | 知道意思但写不出 | 背关键词，不背整段 |
| 时政过时 | 旧文件与新表述冲突 | 以最新官方发布为准 |

## 简答训练法

1. 先只看题目，用 3 分钟写“骨架”（定性句 + 3—5 个分点）。
2. 不看答案，口头复述一遍。
3. 对照参考答案，用红笔补缺失的关键词。
4. 把答案压缩成 5 个关键词，第二天只看关键词复述。
5. 一周后随机抽 2 题，限时 8 分钟重写。

## 考前 24 小时

- 不做新题，只回炉错题和高频框架。
- 把易混对比表、简答骨架、固定表述各过一遍。
- 准备好证件、文具、水，确认考场和时间。
- 提前睡，不熬夜背新内容。
- 进考场前只翻一页“高频关键词”，不与人讨论不会的题。

## 考场状态

- 先做会的，建立节奏；难题标记后跳。
- 多选不确定时，优先保住已确定的 2 项，不盲目加项。
- 简答先写骨架，再补展开；宁可多写一个要点，不要空题。
- 最后 5 分钟检查漏答和答题卡，不改已经确定的答案。

## 心态与节奏

- 焦虑时先做 5 道简单题，用正确率把状态拉回来。
- 不追求“全部背完”，追求“高频题不丢分”。
- 每天只设 1 个主任务，完成后就收工，避免假努力。
- 如果连续两天状态差，减少新内容，只做错题回炉。
