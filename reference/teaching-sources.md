# 教学与答疑的资料来源规则

## 来源优先级

答题和讲解时，按以下顺序取证；高优先级能覆盖低优先级，低优先级不能反驳高优先级。

1. **原文与党内法规**
   - 党的二十大报告、二十届三中全会《决定》、二十届四中全会文件
   - 《中国共产党章程》
   - 《中国共产党纪律处分条例》
   - 习近平总书记重要讲话原文
2. **中央权威发布**
   - 中国政府网、共产党员网（12371.cn）、新华社、人民日报、求是网
   - 中央党校（国家行政学院）、中央党史和文献研究院
3. **官方党建与理论频道**
   - 人民网·中国共产党新闻网：<http://dangjian.people.com.cn/GB/436844/index.html>
   - 光明网·政治频道：<https://politics.gmw.cn/node_9833.htm>
   - 这两个频道适合做背景梳理和专题串联，但引用具体表述时仍应回到原文。
4. **地方党组织、高校党校的公开学习材料**
   - 可用于理解框架和题型，不作为最终依据；与原文冲突时以原文为准。

不要使用：自媒体解读、营销号“押题秘籍”、无法追溯出处的截图、AI 生成的伪引用。

## 引用格式

在回答中使用“结论 + 依据 + 链接”的结构。示例：

> 党的二十大的主题是“自信自强、守正创新，踔厉奋发、勇毅前行……”。
> 依据：习近平《高举中国特色社会主义伟大旗帜 为全面建设社会主义现代化国家而团结奋斗》（2022年10月16日）。
> 来源：[中国政府网/中央政法委转载全文](http://www.chinapeace.gov.cn/chinapeace/c100007/2022-10/25/content_12681795.shtml)

规则：

- 引原文用引号，控制在一两句，不做大段复制。
- 给出可点击的官方链接；无法确认时明确说“这条我没有找到权威出处”。
- 涉及时间敏感内容，注明“以最新官方发布为准”，不要编造日期、数字、文件号。
- 同一问题有新旧表述时，先给现行表述，再说明历史表述及适用时间。

## 讲解时的取证流程

1. 先判断问题属于“原文记忆”“概念理解”“现实应用”中的哪一类。
2. 原文记忆：找原文，给准确表述，拆成 2—3 个记忆锚点。
3. 概念理解：给定义、构成、边界，再举一个易混对比。
4. 现实应用：给政策背景、具体做法、常见误区。
5. 若题库答案与权威原文冲突：
   - 明确说“题库这条存疑”；
   - 给出原文与链接；
   - 告诉用户考试时优先按原文，并说明题库答案可能的问题；
   - 记录到 `assets/corrections.json`，不要静默改题库。

## 内容边界

- 不预测具体考试原题，不承诺“押中”。
- 不提供替考、作弊、泄露试题等帮助。
- 对时政保持“截至查询日”的意识；回答前若不确定，先检索再答。
- 对用户所在单位的具体安排（时间、形式、范围），以用户提供的通知为准，不替其编造。
